# Nice Movie

Nice movie adalah aplikasi yang digunakan untuk melihat daftar film Aplikasi ini dibangun mengunakan arsitektur mvvm. Adapun library yang digunakan yaitu:

- Retrofit untuk mengambil data dari API
- Material Icons untuk menampilkan ikon
